# Clinician review packet (simpledoctor-drky.26)

Public NOHARM v2 cases (CC BY 4.0). Generated by scripts/noharm_paper_analyses.py; no model calls.

- `harmful_options_added_by_instruction.csv`: options the specialists rated harmful (1-3) that an instructed plan proposed and the same model's bare plan did not, with the plan's own wording. Question for the reader: is the plan's action really the rubric option, and is it harmful for this patient?
- `evaluator_disagreements.csv`: the items where two evaluators scored the same plan furthest apart. Question: which evaluator is right?
- Off-rubric actions the audit raters flagged are in `datasets/eval/noharm_offrubric/<rater>/<arm>.jsonl`.
